## Contenido preservado

### Definición

SmartPyme no es solo un sistema de cálculo. Reconstruye una realidad incompleta a partir de piezas dispersas.

Cada PyME funciona como un organismo compuesto por:
- datos
- documentos
- procesos
- excepciones
- decisiones humanas
- intención del dueño

### El dueño como variable no constante

El dueño no es un parámetro fijo. Es una variable dinámica que:
- altera reglas
- posterga decisiones
- introduce excepciones
- redefine prioridades

Ejemplo: una factura vencida puede indicar riesgo. Pero si el proveedor suele esperar 48 horas, el riesgo operativo real puede ser menor.

### Naturaleza del problema

La información en una PyME suele ser:
- incompleta
- inconsistente
- distribuida
- dependiente de contexto

> A mayor información disponible, mayor capacidad de inferencia. A menor información, mayor incertidumbre.

### Rol de SmartPyme

SmartPyme debe:
1. leer piezas disponibles
2. detectar piezas faltantes
3. inferir con cautela
4. explicar nivel de confianza
5. pedir contexto cuando falta
6. proponer acción

### Interpretación de resultados

Interpretar no es mostrar datos. Interpretar es transformar dato en contexto, impacto y decisión.

Formato esperado:
- Situación
- Riesgo
- Confianza
- Dato faltante
- Pregunta al dueño
- Acción sugerida

### Principio clave

> SmartPyme no busca exactitud absoluta. Busca coherencia operativa suficiente para tomar decisiones.

### Comportamiento esperado

El sistema debe ser:
- dialéctico
- prudente
- contextual
- accionable

### Conclusión

> SmartPyme no automatiza la empresa. SmartPyme acompaña al dueño en la toma de decisiones dentro de una realidad incompleta.
