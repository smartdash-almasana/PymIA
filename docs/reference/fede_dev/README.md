# Material de referencia para Fede Dev

## Propósito

Este directorio reúne documentos conceptuales y prototipos visuales entregados para orientar el cierre de productización de Servicio 1.

Puede utilizarse para comprender:

- la visión de SmartPyme como laboratorio operacional;
- el lenguaje de producto y la propuesta de valor;
- ideas de experiencia, presentación y recorrido;
- conceptos históricos sobre memoria, artefactos y continuidad;
- variantes visuales que pueden inspirar la UX final.

## Nivel de autoridad

**Este material es de referencia y no constituye autoridad productiva.**

Si existe una contradicción, la prioridad obligatoria es:

1. código, contratos y tests vigentes del repositorio;
2. guardrails y decisiones activas de Servicio 1;
3. roadmap vigente de Fede Dev en el Hub PymIA;
4. estos documentos conceptuales y prototipos.

Las referencias históricas a Hermes, factoría, LLM en runtime, automatización autónoma u otros alcances retirados **no reactivan ni autorizan** esos componentes.

## Límites para la implementación

Este material no autoriza a modificar ni redefinir:

- `pymia/smartpyme/service_1_product_pipeline_v1.py`;
- el contrato semántico central;
- las fórmulas de capacidades;
- las autorizaciones de ejecución o entrega;
- las reglas fail-closed;
- la conciliación gobernada;
- la taxonomía canónica de Servicio 1.

Fede Dev puede tomar de aquí lenguaje, flujos, ideas visuales y criterios de producto para su unidad de UX, conectores de archivos, operación multiempresa mínima y entrega.
