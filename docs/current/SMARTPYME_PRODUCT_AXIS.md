# SmartPyme — memoria de producto

SmartPyme conserva la visión comercial y operacional del laboratorio PyME. Esa memoria puede orientar lenguaje, dolores y entregables, pero no gobierna código ni arquitectura.

Reglas vigentes:

- la landing no gobierna el producto;
- pilotos y ofertas no autorizan capacidades;
- el lenguaje comercial no amplía el estado técnico;
- Servicio 1 solo avanza mediante su raíz canónica, tests y evidencia.
