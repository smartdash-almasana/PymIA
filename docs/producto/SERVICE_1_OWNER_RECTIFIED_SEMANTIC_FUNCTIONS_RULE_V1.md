## Regla rectora

PymIA puede proponer funciones semánticas probables para columnas y campos usando headers, estructura, patrones de valores, rubro declarado, intención del dueño, evidencia previa y matrices clásicas de PyMEs, comercios y organizaciones.

La rectificación del dueño PyME convierte una función probable en función operativa para Servicio 1.

## Tres niveles

RAW_HEADER: lo que el archivo dice.

PYMIA_INFERRED_FUNCTION: lo que PymIA propone como significado probable.

OWNER_RECTIFIED_FUNCTION: lo que el dueño confirma, corrige, rechaza o califica.

Sólo OWNER_RECTIFIED_FUNCTION puede alimentar evidencia operativa posterior.

## Cadena sana

Archivo XLSX
→ estructura
→ propuesta PymIA
→ rectificación del dueño
→ función operativa
→ perfil de evidencia
→ herramienta candidata
→ revisión de operador

## Relación con Column Confirmation

Column Confirmation no confirma solamente nombres de columnas.

Column Confirmation confirma o corrige la función de negocio de cada columna relevante.

## Invariante estable

PymIA propone.

El dueño PyME rectifica.

La FSM registra.

Las tools ejecutan.

Los archivos son el producto.

## Consecuencia para futuros hitos

Ningún ruteo futuro de Servicio 1 debe depender de headers crudos solamente.

Debe depender de funciones semánticas inferidas por PymIA y rectificadas por el dueño PyME.
