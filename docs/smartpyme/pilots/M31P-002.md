# M31P-002 — Piloto asistido interno con fixture textil

## Estado

PARTIAL_INTERNAL_REALISTIC_CASE

## Naturaleza del caso

Este piloto usa un fixture Excel existente en el repositorio como caso interno realista.

No es cliente real.

No es producto.

No declara PASS_OPERATIVO de M31-P por sí solo.

## Fuente de evidencia

Archivo usado:

```text
prueba_excels/la_textil_cosida_srl_mar_abr_may_2026.xlsx
```

Evidencia de uso existente en tests:

- `tests/test_excel_evidence.py` usa este archivo como `TEXTIL_XLSX`.
- `tests/test_document_ingestion.py` usa este archivo en flujo de intake operacional.
- El test de ingestion espera salida con `[Auditoría Operacional Activa]`.
- El test de ingestion espera señal `Concentración de SKU (PYME_033)`.
- El routing posterior de `quiero ver PYME_033` identifica `ventas_por_sku` como evidencia faltante.

protocol_steps_applied:

  - evidence_review
