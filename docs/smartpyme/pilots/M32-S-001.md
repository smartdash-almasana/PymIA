# M32-S-001 — Simulación Controlada Interactiva por Telegram

## Estado

PARTIAL_DELIVERY

## Caso

Distribuidora Mayorista Don Roque

## Naturaleza

- `case_type = simulated_controlled_interactive`
- `counts_for_pass_m32 = false`
- no producto
- no cliente real
- no autonomía

## Evidencia Conversacional

### Turno 1

Usuario:

```text
Hola, tengo una distribuidora y no me cierra la caja.
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Entiendo tu consulta. Para ayudarte necesito más contexto operativo. ¿Querés revisar ventas, costos, stock, caja o subir un Excel?
```

### Turno 2

Usuario:

```text
Me llamo Roque Pérez. La empresa es Distribuidora Don Roque. Compramos productos de consumo masivo y revendemos a kioscos y almacenes. Somos 8 personas. Vendemos por vendedores propios y distribuidores.
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Entiendo tu consulta. Para ayudarte necesito más contexto operativo. ¿Querés revisar ventas, costos, stock, caja o subir un Excel?
```

### Turno 3

Usuario:

```text
No sé si gano plata. Entra y sale plata todo el tiempo y no sé cuánto gano por producto.
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Para analizar si estas ganando plata necesito:
- ventas del periodo
- costos o compras
- gastos fijos

Podes subir un Excel con estos datos o indicarme los valores?
```

### Turno 4

Usuario sube:

```text
distribuidora_mayorista_compleja.xlsx
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Documento recibido: distribuidora_mayorista_compleja.xlsx. Ya lo guarde y podes pedirme el analisis cuando quieras.
```

### Turno 5

Usuario:

```text
Analizá el Excel y decime qué se puede saber y qué falta.
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Resumen estructural del Excel:
Archivo: 20260606195049_distribuidora_mayorista_compleja.xlsx
Hojas: 1
- Hoja 'OPERACION': rows=5001, cols=8, empty=no
  Columns preview: fecha, cliente, ruta
```

### Turno 6

Usuario:

```text
Dame un resumen claro y próximos pasos.
```

Bot:

```text
[PymIA:TELEGRAM_RUNTIME] Entiendo tu consulta. Para ayudarte necesito más contexto operativo. ¿Querés revisar ventas, costos, stock, caja o subir un Excel?
```

## Conclusiones

- Telegram recibe texto.
- Telegram recibe archivo.
- El archivo fue guardado/cacheado.
- El bot generó resumen estructural parcial del Excel.
- El bot pidió evidencia antes de analizar rentabilidad.
- El bot no inventó margen ni diagnóstico.
- El bot perdió continuidad/intención después del archivo.
- El bot no produjo reporte mínimo contextual.
- El bot parece usar `telegram_runtime` simple, no `anamnesis_fsm` completa.
- `GAP-M32S-001` confirmado.

## Aprendizajes

1. El canal Telegram básico funciona.
2. La recepción documental funciona.
3. El análisis estructural de Excel funciona parcialmente.
4. La continuidad conversacional Telegram es insuficiente.
5. La FSM clínica/anamnesis no está integrada en el runtime Telegram observado.
6. Próximo slice técnico futuro debería ser integración Telegram -> FSM/orquestación, pero NO implementarlo ahora.
