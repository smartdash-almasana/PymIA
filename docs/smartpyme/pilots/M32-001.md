## Aprendizajes para PymIA

1. **Separación de evidencia**: M32 debe distinguir explícitamente evidencia heredada del repositorio de evidencia generada por la corrida específica del piloto.

2. **Hallazgos derivados**: los tests existentes sobre fixtures pueden proveer hallazgos verificables sin ejecutar código productivo nuevo.

3. **Protocolo aplicable documentalmente**: el protocolo M31 puede ejecutarse sobre artefactos existentes para medir tiempos de operación documental y practicar el flujo.

4. **Señales operativas como camino de repetibilidad**: PYME_033 y otras señales detectadas por tests ofrecen caminos útiles para evaluar repetibilidad de señal operacional y evidencia faltante.

5. **Limitación de caso simulado**: un caso simulado controlado cuenta como práctica documental, pero no como piloto válido para PASS M32 salvo que se declare explícitamente su naturaleza y se complemente con casos reales.
